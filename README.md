# The Anatomy of an AI Agent - for Knowledge Workers

Terms such as model, instructions, tools, knowledge, context, memory, and orchestration are often used when describing AI agents, but it isn’t always clear what each one does or how they fit together. This session takes an AI agent apart and follows a request as it moves through the system, showing what distinguishes an agent from a simple conversation with an AI assistant.

We’ll explore how instructions guide an agent’s behavior, how knowledge sources help it answer questions, how context and memory influence its responses, and how tools allow it to perform tasks. Using examples from Microsoft 365 Copilot Agent Builder and SharePoint agents, we’ll connect these concepts to agents you can create and use without writing code. We’ll also explain where technologies such as MCP fit, and why permissions, security, and human oversight remain important even when the platform handles much of the underlying complexity.

By the end of the session, you’ll have a practical mental model of how AI agents work, what they can and cannot do, and what to consider when creating or using agents in your organization.
